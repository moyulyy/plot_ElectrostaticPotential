静电势表面查看器 (ESP Surface Viewer) — 便携版
================================================

双击 ESP_Viewer.exe 即可运行, 无需安装 Python, 可整个文件夹拷到其它
Windows 10/11 电脑使用 (建议一并拷贝 _internal 目录)。

显示内容
--------
VASP 风格的 "电荷密度等值面 + 静电势彩虹着色" (与 VESTA 参考图一致)。
启动后自动载入内置样例 (samples/, 已降采样)。

放自己的数据
------------
把 VASP 算例目录 (含 LOCPOT 与 CHGCAR 两个文件) 放在:
    · 与本 exe 同级的 test\   或
    · 与本 exe 同级的 data\
程序会自动读取其中的 LOCPOT/POT 与 CHGCAR/CHG。
也可在程序里点 "数据目录 → 浏览" 手动选择, 再点 "重新载入"。
也可以用命令行指定目录:  ESP_Viewer.exe  D:\path\to\vasp\dir

操作
----
· 视角: 3D 视图上方 6 个按钮 (俯视/正视/右视/仰视/后视/左视) + 重置视角;
        拖动旋转, 滚轮缩放 (正交投影)。
· 等值面: 调节 "密度水平" (e/Å³, 常用 0.1)。
· 颜色: 选配色方案; 左侧彩条随 "色条范围" (eV) 实时更新。
· 导出 PNG: 右上角按钮 (含彩条)。

常见问题
--------
1. 3D 窗口空白 → 更新显卡驱动; 或在有 GPU 的机器上运行。
2. 打开很慢 → 首次启动需要初始化 QtWebEngine, 属正常。
